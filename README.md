# Mute-bind
Программа на с++, которая позволяет по нажатию горячей клавиши отключить\убавить звук приложения в микшере windows. (подобно CTRL + M из PUBG (для верси 1.0))
В версии 1.1 прогрмма работает подобно F7 из PUBG снижая громкость до определнного значения (min 10%)
Скачать программу можно во вкладке "Tag", так же там будут выходить обновления\багфиксы
