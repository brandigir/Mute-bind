# Mute-bind
Программа на с++, которая позволяет по нажатию горячей клавиши отключить\убавить звук приложения в микшере windows.




Версия 1.0 выключает звук приложения.
Версии 1.1 понижает уровень громкости.
Версия 1.2 объединение выключения звука и понижения громкости а так же изменение уровня понижения.


Скачать программу можно во вкладке "Tag", так же там будут выходить обновления\багфиксы
